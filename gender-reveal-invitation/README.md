# Animated Gender Reveal Invitation (5 themes, party or reveal mode)

Mobile-first animated digital gender reveal invitation, sold as an editable template.

- **Party mode**: "Boy or Girl?" invitation with Team Boy / Team Girl badges and a vote in the RSVP.
- **Reveal mode**: the invitation keeps the secret on the opening screen and in the link preview, then reveals "It's a Boy!" or "It's a Girl!" with matching colors and confetti.

Files: `index.html` (the invitation), `editor.html` (no-code editor), `INSTRUCTIONS.md` / PDF, `dist/Gender-Reveal-Animated-Invitation.zip`.

Themes: `balloon` (Balloon Pop), `bows` (Bows or Bowties), `stars` (Starlight Reveal), `cake` (Cake Reveal), `boho` (Boho Neutral). Try one with `index.html?theme=stars`.

After changing `index.html`, run `node tools/sync-editor.js` so the editor carries the new template.
