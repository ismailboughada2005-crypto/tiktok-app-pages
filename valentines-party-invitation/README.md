# Animated Valentine's / Galentine's Party Invitation (5 themes)

Mobile-first animated digital invitation with realistic illustrations and a cinematic moving background (falling rose petals, hearts, bokeh and candle light), sold as an editable template.

- `index.html`: the invitation (single file, inline CSS/JS/SVG, Google Fonts only).
- `editor.html`: no-code editor with live phone preview, theme swatches, full-screen preview and download.
- `INSTRUCTIONS.md` / PDF in the zip: buyer guide (Netlify Drop / GitHub Pages).
- `dist/Valentines-Party-Animated-Invitation.zip`: what the buyer downloads.

Themes: `roses` (Red Roses), `blush` (Blush Love Letter), `candy` (Candy Hearts), `midnight` (Midnight Romance), `garden` (Love in Bloom). Try one with `index.html?theme=midnight`.

After changing `index.html`, run `node tools/sync-editor.js` so the editor carries the new template.
