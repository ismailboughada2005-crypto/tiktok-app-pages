# Animated Baby Shower Invitation (5 themes)

Mobile-first animated digital baby shower invitation, sold as an editable template.

- `index.html`: the invitation (single file, inline CSS/JS/SVG, Google Fonts only).
- `editor.html`: no-code editor with live phone preview, theme swatches, full-screen preview and download.
- `INSTRUCTIONS.md` / `dist/.../INSTRUCTIONS.pdf`: buyer guide (Netlify Drop / GitHub Pages).
- `dist/Baby-Shower-Animated-Invitation.zip`: what the buyer downloads.

Themes: `cloud` (Cloud Nine), `peach` (Peach Blossom Garden), `safari` (Little Safari), `lavender` (Lavender Dream), `bee` (Sweet as Can Bee). Try one with `index.html?theme=safari`.

After changing `index.html`, run `node tools/sync-editor.js` so the editor carries the new template.
